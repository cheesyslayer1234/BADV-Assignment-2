Eligible-registrants list (Merkle root)

A faster way to approve a whole list of eligible wallets at once, instead of authorising them one-by-one above. In plain terms: you give it your list of eligible wallet addresses, it boils that list down to one short code (the "root"), and you publish just that code here. Anyone on your original list can then apply automatically — the site checks them against the list for you, with nothing for them to copy or paste.

  1. On your computer, copy eligible-registrants.example.json to eligible-registrants.json and put your real list of wallet addresses in it.
  2. Run npm run generate-merkle-root. It prints a root and writes frontend/generated/eligibility-proofs.json.
  3. Commit & push that generated file so it goes live on your site, then paste the printed root below and publish it.
