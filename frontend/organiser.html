Eligible registrants

This is the whole eligibility system now — no more authorising wallets one-by-one on-chain. Add or remove wallet addresses below; this page builds the Merkle tree and root for you, right here in the browser. Nobody needs to understand Merkle trees, touch VS Code, or run any script.

  Loading current list…

Why is there still one manual step?

"Publish root to blockchain" is the part that actually matters — it's the one on-chain source of truth, and it's a single click, right here. The list of raw addresses is only used so applicants' browsers can work out their own proof automatically; it has to live somewhere public for that. This project is a static site (no server of its own), so after adding/removing addresses, use "Copy updated list JSON" and paste it over the contents of frontend/generated/eligible-registrants.json using GitHub's own web editor (open the file on github.com, click the pencil icon, paste, commit) — no git, no VS Code, works from a phone. The site redeploys automatically within a minute or two. Applicants who were already eligible aren't affected by this step; it only matters for people you've just added or removed.
